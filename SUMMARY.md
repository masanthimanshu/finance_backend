# Finance Backend

## Project Purpose

Built a secure, modular backend for a personal finance assistant that converts natural-language transaction input into structured financial records and supports authenticated user workflows.

## Core Technologies & Architecture

Node.js, Express, MongoDB, Mongoose, JWT, Zod, Cloudflare AI, and Docker; built with a modular route-controller-model architecture and middleware-based security for scalable backend services.

## Key Contributions

Implemented phone-based OTP authentication, access/refresh token flows, protected transaction endpoints, AI-assisted transaction categorization, and category-level aggregation for reporting and insights.

## Impact & Value

Delivered a reliable foundation for secure finance data capture and reporting, reducing manual entry effort through automation while keeping the system extensible for future product growth.
